# Website behavior. Programmed like CSS.

VSN adds state, events, and bindings to the HTML you already wrote. Because if CSS can describe how a website looks, surely it can describe how it behaves. Surely.

[Get started →](/get-started) · [Explore the examples](/examples)

## HTML first. Behavior alongside it.

Keep your server-rendered pages. Add a small CFS behavior, mount VSN once, and let the markup do the talking. No virtual DOM. No component renderer. Just a slightly more ambitious relationship with selectors.

## From the Developer

“We know how much developers love CSS, so building a language to program website functionality akin to CSS was a no-brainer. You're welcome!”
